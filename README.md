# Dharanidharan D Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript.

## Run
Open `index.html` in a browser.

## Notes
- GitHub and LinkedIn links are wired to the provided profiles.
- Project GitHub/live-demo buttons are intentionally not fabricated because no project URLs were supplied.
- The contact form opens the visitor's default email client.
- Includes responsive navigation, scroll reveal animations, futuristic AI visual, and dark/light theme toggle.
